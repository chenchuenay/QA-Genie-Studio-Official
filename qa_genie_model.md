# QA Genie AI Context Model

QA Genie is a production-oriented AI testcase generation system.

The application focuses on:
- realistic enterprise QA workflows
- deterministic repair
- parser hardening
- truncation recovery
- forensic telemetry
- export integrity
- SQLite persistence safety
- realistic manual QA testcase generation

## Core Generation Philosophy
Generate realistic QA workflows instead of generic AI responses.

## Current Product Limits

### CORE
- 8 cases/generation
- 1 free generation/day
- +5 rewarded generations/day

### PRO
- 16 cases/generation
- 15 generations/day

## Core Technical Systems
- AI generation
- parser recovery
- deterministic repair
- fallback generation
- realism enforcement
- SQLite locking
- export mapping
- telemetry tracking

- preserve deterministic architecture
- preserve export contracts
